# D&D Gym

Phase 1 of an Android-first, offline Flutter app for a single gym owner.

## Included

- Premium black-and-gold splash and interface
- Dashboard with total clients, active plans, and memberships ending soon
- Local SQLite client storage with add, edit, delete, list, and search flows
- Locally stored client photos
- Client profile with prepared Overview, Progress, Workout, Diet, and Payments sections
- Reusable theme, avatar, empty state, repository, and profile components

Later-phase features such as notifications, graphs, workout management, payment history, and backup are intentionally excluded.

## Run

```sh
flutter pub get
flutter run
```
